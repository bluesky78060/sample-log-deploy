💾 저장 모드 선택 ● 확인 중

저장 모드란?
데이터를 어디에 저장할지 선택합니다. Firebase 연결 상태에 따라 사용 가능한 모드가 달라집니다.

모드를 변경해도 기존 데이터는 삭제되지 않습니다. 클라우드 모드는 Firebase 연결이 필요합니다.

🔐 Firebase 인증 파일 ● 미등록

인증 파일이란?
Firebase 접근을 위한 인증 파일(firebase-auth.json)을 등록해야 클라우드 동기화가 활성화됩니다. 인증 파일은 관리자에게 받으세요.
