# 분석결과 입력 기능 문서

> v1.7.90 ~ | 수질분석 · 잔류농약 분석결과 입력/조회/내보내기

---

## 1. 개요

시료 접수 후 분석 결과를 입력하고, 다른 사용자가 결과를 조회할 수 있는 기능입니다.

| 시료 타입 | 분석 기준 | 입력 방식 | 데이터 키 |
|----------|----------|----------|----------|
| **수질분석** | 지하수법 시행규칙 별표9 (20항목) | 고정 항목 입력 | `waterTestResults_{year}` |
| **잔류농약** | 농산물품질관리원 515종 | 동적 행 추가 | `pesticideTestResults_{year}` |

## 2. 수질분석 결과 입력

### 2.1 분석 항목 (지하수법 시행규칙 별표9)

#### 일반오염물질 (6항목)

| No | 항목 | 단위 | 생활용수 기준 | 농업용수 기준 |
|----|------|------|------------|------------|
| 1 | pH | - | 5.8~8.5 | 6.0~8.5 |
| 2 | EC | µS/cm | - | - |
| 3 | 총대장균군 | 군수/100mL | 5,000 이하 | - |
| 4 | 질산성질소 | mg/L | 20 이하 | 20 이하 |
| 5 | 염소이온 | mg/L | 250 이하 | 250 이하 |
| 6 | 카드뮴 | mg/L | 0.01 이하 | 0.01 이하 |

#### 특정유해물질 (10항목, 공통)

| No | 항목 | 단위 | 생활용수 기준 | 농업용수 기준 |
|----|------|------|------------|------------|
| 7 | 비소 | mg/L | 0.05 이하 | 0.05 이하 |
| 8 | 시안 | mg/L | 0.01 이하 | 0.01 이하 |
| 9 | 수은 | mg/L | 0.001 이하 | 0.001 이하 |
| 10 | 유기인 | mg/L | 0.0005 이하 | 0.0005 이하 |
| 11 | 페놀 | mg/L | 0.005 이하 | 0.005 이하 |
| 12 | 납 | mg/L | 0.1 이하 | 0.1 이하 |
| 13 | 6가크롬 | mg/L | 0.05 이하 | 0.05 이하 |
| 14 | 트리클로로에틸렌 | mg/L | 0.03 이하 | 0.03 이하 |
| 15 | 테트라클로로에틸렌 | mg/L | 0.01 이하 | 0.01 이하 |
| 16 | 1,1,1-트리클로로에탄 | mg/L | 0.15 이하 | 0.3 이하 |

#### 특정유해물질 (4항목, 생활용수 전용)

| No | 항목 | 단위 | 생활용수 기준 |
|----|------|------|------------|
| 17 | 벤젠 | mg/L | 0.015 이하 |
| 18 | 톨루엔 | mg/L | 1 이하 |
| 19 | 에틸벤젠 | mg/L | 0.45 이하 |
| 20 | 크실렌 | mg/L | 0.75 이하 |

### 2.2 입력 방법

#### 방법 1: 접수 대장 모달 (건별 입력)

1. 수질분석 접수 대장 목록에서 **"결과입력"** 버튼 클릭
2. 모달에서 검사일자, 분석 항목별 결과값 입력
3. 각 항목 옆에 **기준값** 표시, 초과 시 빨간색 경고
4. **불검출(ND)** 체크박스로 간편 입력
5. 판정(미판정/적합/부적합) 선택 후 **저장**

```
모달 구조:
┌─ 시료 정보 (접수번호, 성명, 시료명, 검사항목) ─┐
├─ 검사일자 입력                                 │
├─ 분석 항목 테이블                              │
│  No. | 항목명 | 단위 | 기준 | 결과값 | ND | 상태│
│   1  | pH     |      | 5.8~8.5 | [7.2] |   | ✓ │
│   2  | EC     |µS/cm |   -     | [350] |   | ✓ │
│  ...                                          │
├─ 판정: ○미판정  ○적합  ○부적합                  │
└─ [닫기] [저장]                                 │
```

#### 방법 2: 결과 입력 페이지 (일괄 입력)

1. 접수 대장 툴바에서 **"분석결과"** 버튼 클릭 → 별도 창
2. 전체 시료를 테이블로 표시
3. **셀 클릭 편집**, **엑셀 붙여넣기** 지원
4. 키보드 네비게이션 (Tab, Enter, Arrow)
5. 검사항목 필터 (전체/생활용수/농업용수)
6. **엑셀 내보내기** (생활용수/농업용수 별도 시트)

### 2.3 UI 색상 구분 (결과 입력 페이지)

| 구분 | 색상 | 설명 |
|------|------|------|
| 일반오염물질 | 초록 | pH, EC, 총대장균군, 질산성질소, 염소이온, 카드뮴 |
| 특정유해물질 (공통) | 노랑 | 비소~1,1,1-트리클로로에탄 (10항목) |
| 생활용수 전용 | 보라 | 벤젠, 톨루엔, 에틸벤젠, 크실렌 |

## 3. 잔류농약 분석결과 입력

### 3.1 분석 항목

- **총 525종** (농산물품질관리원 463종 SET 기준)
- **GC-MS/MS**: 258종
- **LC-MS/MS**: 267종
- 출처: `잔류농약성분목록(LC,GC구분).xlsx`
- 데이터 파일: `src/shared/pesticide-data.js`

### 3.2 입력 방법: 접수 대장 모달

1. 잔류농약 접수 대장 목록에서 **"결과입력"** 버튼 클릭
2. 모달에서 검사일자 입력
3. **"전체 불검출"** 또는 **"추가"** 선택

#### 전체 불검출인 경우

- **"전체 불검출"** 버튼 클릭
- 판정이 자동으로 "불검출"로 설정
- 저장하면 접수 대장의 판정도 "불검출"로 연동

#### 검출 농약이 있는 경우

- **"추가"** 버튼 클릭 → 행 추가
- **농약명**: 영문명 입력 시 525종에서 자동완성 검색
- **분석법**: GC 또는 LC 선택
- **검출량**: mg/kg 단위 수치 입력
- 여러 농약이 검출되면 행을 계속 추가
- 저장하면 판정이 자동으로 "검출"로 설정

```
모달 구조:
┌─ 시료 정보 (접수번호, 성명, 의뢰물품, 목적) ───┐
├─ 검사일자 입력                                 │
├─ 판정: ○미판정  ○불검출  ○검출                  │
├─ 검출 농약  3건    [✓ 전체 불검출]  [+ 추가]    │
│  No. | 분석법 | 농약명 (자동완성) | 검출량 | X   │
│   1  |  GC   | Chlorpyrifos     | 0.05  | ✕  │
│   2  |  LC   | Acetamiprid      | 0.02  | ✕  │
│   3  |  GC   | Bifenthrin       | 0.01  | ✕  │
└─ [닫기] [저장]                                 │
```

### 3.3 조회 페이지

1. 접수 대장 툴바에서 빨간 **"분석결과"** 버튼 클릭 → 별도 창
2. 시료별 검출 농약을 행으로 표시 (rowSpan 병합)
3. 필터: 전체 / 검출 / 불검출 / 미입력
4. 체크박스 선택 후 버튼 클릭 → 선택 시료만 표시

```
조회 테이블:
접수번호│접수일자│성명│의뢰물품│목적│검사일자│검출수│ 농약명           │검출량│분석법│판정
───────┼───────┼───┼──────┼───┼──────┼─────┼────────────────┼─────┼─────┼────
       │       │   │      │   │      │     │ Chlorpyrifos   │ 0.05│  GC │
  1    │01-02  │정명│ 토양 │인증│04-03 │ 3종 │ Acetamiprid    │ 0.02│  LC │검출
(병합) │(병합) │(병)│(병합)│(병)│(병합)│(병합)│ Bifenthrin     │ 0.01│  GC │(병합)
───────┼───────┼───┼──────┼───┼──────┼─────┼────────────────┼─────┼─────┼────
  2    │01-03  │김동│  무  │참고│      │불검출│ 전체 불검출     │     │     │불검출
```

### 3.4 엑셀 내보내기

- 검출 농약별로 행 분리 (접수 정보는 셀 병합)
- 농약명, 검출량(mg/kg), 분석법 각각 별도 셀
- 접수번호, 접수일자, 성명, 의뢰물품, 목적, 검사일자, 검출수, 판정 → 세로 병합

## 4. 판정 연동

### 수질분석

| 모달 판정 | 접수 대장 판정 버튼 |
|----------|------------------|
| 적합 (pass) | 적합 (초록) |
| 부적합 (fail) | 부적합 (빨강) |
| 미판정 | - |

### 잔류농약

| 분석결과 동작 | 판정 자동 결정 | 접수 대장 반영 |
|-------------|-------------|-------------|
| "전체 불검출" 클릭 | → 불검출 자동 선택 | → "불검출" 표시 |
| 검출 농약 추가 후 저장 | → 검출 자동 결정 | → "검출" 표시 |
| 수동 판정 변경 | → 수동 선택 우선 | → 수동 결과 반영 |

## 5. 데이터 저장

### 저장 구조

```
localStorage (오프라인 우선)
├── waterTestResults_2026      ← 수질 분석 결과
│   └── { "logId_0": { testDate, pH, ec, nitrate, ..., judgment } }
│
└── pesticideTestResults_2026  ← 잔류농약 분석 결과
    └── { "logId": { testDate, judgment, allNd, detections: [...] } }
```

### Firestore 동기화

```
Firestore (온라인 동기화)
├── waterTestResults_2026/     ← 수질
│   └── {logId_0}: { ...필드값들, updatedAt }
│
└── pesticideTestResults_2026/ ← 잔류농약
    └── {logId}: { testDate, judgment, allNd, detections, updatedAt }
```

| 동작 | localStorage | Firestore |
|------|-------------|-----------|
| 저장 | 즉시 저장 | 비동기 batchSave |
| 로드 | 로컬 먼저 | 클라우드 병합 (updatedAt 비교) |
| 충돌 해결 | - | 최신 updatedAt 우선 |
| 오프라인 | 정상 동작 | 온라인 복귀 시 자동 동기화 |

## 7. 농약 데이터 관리

### 데이터 파일

- 경로: `src/shared/pesticide-data.js`
- 출처: `잔류농약성분목록(LC,GC구분).xlsx`
- 구조: `{ engName: '영문명', method: 'GC' | 'LC' }`

### 전역 함수

```javascript
window.searchPesticides(query, method, limit)  // 자동완성 검색
window.getPesticidesByMethod('GC')              // 분석법별 필터
window.getPesticideStats()                      // 통계 {total, gc, lc}
```

### 데이터 갱신 방법

1. 새 엑셀 파일 준비 (GC-MSMS, LC-MSMS 시트)
2. Node.js 스크립트로 `pesticide-data.js` 재생성
3. `npm run build`로 빌드

## 8. 보안

### XSS 방지

- 모든 사용자 입력은 `textContent` 또는 `dataset`으로 처리
- `innerHTML` + template literal 패턴 전면 제거 (v1.7.90)
- 주소 자동완성 17건 XSS 취약점 수정 완료 (전 시료 타입)
- 엑셀 내보내기 시 `sanitizeExcelAoa()`로 수식 주입 방지

### Firestore 보안

- `contextIsolation: true`, `nodeIntegration: false`
- 팝업 창 외부 URL 네비게이션 차단
- Firebase 인증 파일 기반 접근 제어
