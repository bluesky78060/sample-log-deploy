시작하기

앱 설치 및 실행

Electron 데스크톱 앱 (권장)
  1. 제공받은 설치 파일을 실행합니다 (Windows: .exe, macOS: .zip)
  2. 설치 마법사를 따라 설치를 완료합니다
  3. 바탕화면 또는 시작 메뉴에서 시료접수대장 아이콘을 클릭하여 실행합니다
웹 브라우저 (대안)

GitHub Pages에서도 동일한 기능을 사용할 수 있습니다.

  1. 웹 브라우저(Chrome, Edge, Firefox 등)를 실행합니다
  2. 제공받은 웹 주소로 접속합니다
  3. 북마크에 추가하여 빠르게 접근할 수 있습니다
개발 모드로 실행하기 개발자나 관리자의 경우, DevTools와 함께 실행하려면: npm start -- --dev

메인 화면 소개

앱을 실행하면 5가지 시료 타입을 선택할 수 있는 메인 화면이 나타납니다.

시료 타입 설명
토양 시료 토양 성분 분석을 위한 시료 접수
수질 분석 농업용수 수질 검사 시료 접수
퇴액비 퇴비 및 액비 성분 분석 시료 접수
잔류농약 농산물 잔류농약 검사 시료 접수
중금속 토양 중금속 분석 시료 접수

화면 하단 정보

  • 앱 버전 확인 (예: v1.7.52)
  • 마지막 업데이트 날짜
  • 다크 모드 토글 버튼

다크 모드 전환

화면 우측 상단 또는 하단의 다크 모드 버튼을 클릭하면 화면 테마를 어두운 색상으로 변경할 수 있습니다.

  • 야간 작업 시 눈의 피로를 줄일 수 있습니다
  • 설정은 자동으로 저장되어 다음 실행 시에도 유지됩니다
2

시료 접수하기

접수 폼 작성법

1단계: 기본 정보 입력
  • 접수번호: 자동으로 생성됩니다 (연도-순번 형식, 예: 2026-0001)
  • 접수일자: 오늘 날짜가 기본값으로 설정되며, 날짜 선택기로 변경 가능합니다
  • 수령방법: 아이콘을 클릭하여 선택합니다
    • 방문: 직접 방문하여 시료 제출
    • 우편: 우편으로 시료 발송
2단계: 의뢰인 정보
  • 성명: 의뢰인 이름을 입력합니다
  • 전화번호: 숫자만 입력하면 자동으로 하이픈(-)이 삽입됩니다
    • 예: 01012345678 → 010-1234-5678
  • 주소: 우편번호 검색 버튼을 클릭하여 주소를 찾을 수 있습니다
    • 도로명 주소 또는 지번 주소를 검색합니다
    • 주소 선택 후 상세 주소를 추가로 입력합니다
개인정보 보호 의뢰인의 성명, 전화번호, 주소는 민감한 개인정보입니다. 암호화 기능을 활성화하여 안전하게 보관하는 것을 권장합니다. (자세한 내용은 6. 설정 참조)

시료 구분 및 용도 선택

시료 구분 (필지 종류)

드롭다운 메뉴에서 해당하는 항목을 선택합니다.

  • 논
  • 밭
  • 과수
  • 시설 (하우스 등)
  • 임야
  • 성토
용도 (재배 방식)

드롭다운 메뉴에서 해당하는 항목을 선택합니다.

  • 일반재배
  • 무농약
  • 유기
  • GAP (우수농산물관리)
  • 저탄소

필지 정보 추가

필지 추가 방법
  1. + 필지 추가 버튼을 클릭합니다
  2. 새로운 필지 입력란이 나타납니다
  3. 다음 정보를 입력합니다:
    • 작물명: 직접 입력하거나 🔍 검색 버튼을 클릭하여 모달에서 선택합니다
    • 면적: 숫자만 입력하면 자동으로 단위(㎡)가 표시됩니다
      • 예: 1000 → 1,000㎡
    • 지번: 필지의 지번 주소를 입력합니다 (예: 123-4)
  4. 필지를 삭제하려면 해당 필지 행의 X 삭제 버튼을 클릭합니다

작물명 검색 모달

  • 카테고리별로 작물이 분류되어 있습니다 (곡류, 과수류, 채소류 등)
  • 검색창에 작물명을 입력하여 빠르게 찾을 수 있습니다
  • 작물을 클릭하면 자동으로 입력란에 채워집니다

등록 및 초기화

  • 등록 버튼: 입력한 정보를 저장하고 접수 목록에 추가합니다
  • 초기화 버튼: 폼의 모든 입력 내용을 지우고 처음 상태로 되돌립니다
등록 완료 등록에 성공하면 화면 우측 상단에 "시료가 등록되었습니다" 메시지가 나타나며, 폼이 자동으로 초기화되어 다음 시료를 바로 입력할 수 있습니다.

접수 목록 조회

연도별 조회

화면 상단의 연도 선택 드롭다운에서 조회하려는 연도를 선택합니다.

  • 현재 연도가 기본값으로 선택되어 있습니다
  • 과거 데이터를 조회하려면 해당 연도를 선택합니다
데이터가 안 보이는 경우 선택한 연도가 현재 연도와 다른지 확인하세요. 데이터는 연도별로 분리되어 저장됩니다.

필터 기능

용도별 필터

용도 필터 드롭다운에서 특정 재배 방식의 시료만 볼 수 있습니다.

  • 전체
  • 일반재배
  • 무농약
  • 유기
  • GAP
  • 저탄소
완료 상태 필터

완료 상태 드롭다운에서 처리 상태별로 필터링할 수 있습니다.

  • 전체
  • 완료
  • 미완료

고급 검색

고급 검색 섹션을 펼쳐서 더욱 세밀한 조건으로 검색할 수 있습니다.

  • 접수일자 범위: 시작일과 종료일을 지정하여 해당 기간의 시료만 조회합니다
  • 성명 검색: 의뢰인 이름으로 검색합니다 (부분 일치 지원)
  • 접수번호 범위: 특정 접수번호 구간의 시료를 조회합니다
  • 지번 주소 검색: 필지의 지번 주소로 검색합니다

테이블 보기

기본 보기 vs 전체 보기

전체 보기 버튼을 클릭하여 테이블 표시 모드를 전환할 수 있습니다.

  • 기본 보기: 주요 필드만 표시 (접수번호, 성명, 전화번호, 필지 정보, 완료 상태 등)
  • 전체 보기: 모든 필드를 표시 (주소, 수령방법, 우편발송일자 등 포함)
완료 체크박스

각 시료 행의 완료 열에 있는 체크박스를 클릭하여 처리 완료 여부를 표시할 수 있습니다.

  • 체크: 시료 처리 완료
  • 미체크: 처리 진행 중 또는 대기

페이지네이션

한 페이지에 표시할 항목 수를 선택할 수 있습니다.

  • 50건 (기본값)
  • 100건
  • 200건
  • 500건

설정은 자동으로 저장되며, 페이지 하단의 이전 / 다음 버튼으로 페이지를 이동할 수 있습니다.

4

데이터 관리

수정 및 삭제

개별 수정
  1. 접수 목록에서 수정하려는 시료의 수정 버튼을 클릭합니다
  2. 접수 폼에 해당 시료의 정보가 자동으로 입력됩니다
  3. 필요한 항목을 수정합니다
  4. 등록 버튼을 클릭하여 변경 사항을 저장합니다
개별 삭제
  1. 삭제하려는 시료의 삭제 버튼을 클릭합니다
  2. 확인 팝업이 나타나면 확인을 클릭합니다
  3. 해당 시료가 목록에서 제거됩니다
일괄 삭제
  1. 삭제하려는 시료들의 체크박스를 선택합니다 (테이블 좌측)
  2. 화면 상단의 선택 항목 삭제 버튼을 클릭합니다
  3. 확인 팝업에서 확인을 클릭하여 삭제를 완료합니다
주의 삭제된 데이터는 복구할 수 없습니다. 삭제 전에 반드시 백업을 권장합니다.

우편 발송일자 일괄 입력

여러 시료의 우편 발송일자를 한 번에 입력할 수 있습니다.

  1. 대상 시료들의 체크박스를 선택합니다
  2. 우편 발송일자 일괄 입력 버튼을 클릭합니다
  3. 날짜 선택 팝업에서 발송일자를 선택합니다
  4. 확인을 클릭하면 선택한 모든 시료에 발송일자가 기록됩니다

엑셀 내보내기

전체 내보내기
  1. 엑셀 내보내기 버튼을 클릭합니다
  2. 현재 조회 중인 연도의 모든 시료 데이터가 엑셀 파일로 다운로드됩니다
  3. 파일명 형식: 시료접수대장_토양_2026.xlsx
선택 항목 내보내기
  1. 내보내려는 시료들의 체크박스를 선택합니다
  2. 선택 항목 내보내기 버튼을 클릭합니다
  3. 선택한 시료들만 엑셀 파일로 다운로드됩니다

엑셀 파일 형식

  • xlsx 형식으로 저장됩니다
  • 모든 필드가 포함되며, 필지 정보는 별도 열로 분리됩니다
  • 암호화된 데이터는 복호화되어 내보내집니다

엑셀 가져오기 (3단계)

1단계: 서식 다운로드
  1. 엑셀 가져오기 버튼을 클릭합니다
  2. 팝업 화면에서 엑셀 서식 다운로드 버튼을 클릭합니다
  3. 다운로드된 엑셀 템플릿 파일을 열어 데이터를 입력합니다
2단계: 컬럼 매핑
  1. 데이터가 입력된 엑셀 파일을 선택합니다
  2. 엑셀의 각 열이 앱의 어떤 필드에 대응되는지 매핑합니다
    • 자동 감지 기능이 제공됩니다 (열 이름이 일치하면 자동 매핑)
    • 수동으로도 조정 가능합니다
  3. 다음 버튼을 클릭합니다
3단계: 미리보기 및 가져오기
  1. 가져올 데이터가 올바른지 미리보기에서 확인합니다
  2. 오류가 있는 행은 빨간색으로 표시됩니다
  3. 문제가 없으면 가져오기 버튼을 클릭합니다
  4. 데이터가 접수 목록에 추가됩니다
XSS 방지 엑셀 가져오기 시 모든 데이터는 자동으로 새니타이징되어 악성 스크립트 삽입을 방지합니다.

JSON 저장/불러오기

JSON 저장

JSON 저장 버튼을 클릭하면 현재 연도의 모든 데이터를 JSON 형식으로 다운로드할 수 있습니다.

  • 파일명 형식: 시료접수대장_토양_2026.json
  • 원본 데이터 그대로 저장되므로 백업용으로 유용합니다
JSON 불러오기
  1. JSON 불러오기 버튼을 클릭합니다
  2. 이전에 저장한 JSON 파일을 선택합니다
  3. 확인 팝업에서 확인을 클릭하면 데이터가 복원됩니다
JSON vs 엑셀 JSON 파일은 모든 메타 정보를 포함하므로 정확한 백업/복원에 적합하며, 엑셀 파일은 보고서 작성이나 외부 공유에 적합합니다.

자동 저장 기능 (Electron 전용)

Electron 데스크톱 앱에서만 사용할 수 있는 기능으로, 데이터를 파일 시스템에 자동으로 백업합니다.

  1. 자동 저장 설정 섹션에서 폴더 선택 버튼을 클릭합니다
  2. 백업 파일을 저장할 폴더를 선택합니다
  3. 이후 데이터가 변경될 때마다 5초 주기로 자동 저장됩니다
  4. 파일명 형식: auto-save-토양-2026.json

자동 저장의 장점

  • 앱이 예기치 않게 종료되어도 데이터 손실을 방지합니다
  • 별도 백업 없이도 파일 시스템에 실시간 백업됩니다
  • 선택한 폴더에 연도별로 별도 파일이 생성됩니다

통계 및 라벨 인쇄

통계 보기

통계 보기 버튼을 클릭하면 현재 연도의 시료 접수 현황을 다양한 관점에서 확인할 수 있습니다.

  • 구분별 통계: 논, 밭, 과수, 시설, 임야, 성토별 시료 수
  • 목적별 통계: 일반재배, 무농약, 유기, GAP, 저탄소별 시료 수
  • 월별 통계: 1월부터 12월까지 월별 접수 건수 추이
  • 수령방법별 통계: 방문, 우편별 접수 건수

통계 활용 팁

  • 월별 추이를 통해 성수기/비수기를 파악할 수 있습니다
  • 목적별 통계로 인증 농가 비율을 확인할 수 있습니다
  • 통계 화면은 인쇄하여 보고서로 활용할 수 있습니다

라벨 인쇄

선택한 시료들의 주소 라벨을 인쇄할 수 있습니다. (우편 발송용)

  1. 라벨을 인쇄할 시료들의 체크박스를 선택합니다
  2. 라벨 인쇄 버튼을 클릭합니다
  3. 새 창에 주소 라벨이 표시됩니다
  4. 브라우저의 인쇄 기능(Ctrl+P 또는 Cmd+P)을 사용하여 인쇄합니다
라벨 형식 라벨에는 우편번호, 주소, 수신인 이름이 포함되며, A4 용지에 4열로 정렬되어 라벨지에 바로 인쇄할 수 있습니다.

설정

Firebase 인증 파일 등록

클라우드 동기화를 사용하려면 Firebase 인증 파일을 등록해야 합니다.

  1. 메인 화면 또는 각 시료 페이지 상단의 설정 링크를 클릭합니다
  2. Firebase 인증 파일 섹션을 찾습니다
  3. 파일 선택 버튼을 클릭하거나, 파일을 드래그하여 드롭합니다
  4. firebase-auth.json 파일을 선택합니다
  5. 연결 테스트 버튼을 클릭하여 정상 연결을 확인합니다
Firebase 설정 가이드 Firebase 프로젝트 생성 및 인증 파일 만드는 방법은 별도 문서 FIREBASE_SETUP_GUIDE.html를 참조하세요.

Firebase 수동 설정 (접이식)

인증 파일 없이 직접 설정값을 입력할 수도 있습니다. (웹 버전에서 유용)

  1. Firebase 수동 설정 섹션의 헤더를 클릭하여 펼칩니다
  2. 다음 6개 항목을 입력합니다:
    • apiKey
    • authDomain
    • projectId
    • storageBucket
    • messagingSenderId
    • appId
  3. 저장 버튼을 클릭합니다

기관명 설정

인쇄물이나 라벨에 표시될 기관명을 설정할 수 있습니다.

  • 기본값: "봉화군 농업기술센터 안전성분석센터"
  • 변경 후 저장하면 이후 생성되는 문서에 적용됩니다

클라우드 동기화

전체 동기화

전체 동기화 버튼을 클릭하면 현재 연도의 모든 데이터를 Firebase에 업로드합니다.

  • 처음 Firebase를 설정한 경우 이 기능으로 기존 데이터를 클라우드에 올릴 수 있습니다
  • 다른 PC에서 동일한 Firebase 프로젝트에 접속하면 동기화된 데이터를 볼 수 있습니다
개별 마이그레이션

특정 연도의 데이터만 Firebase로 옮길 수 있습니다.

  1. 연도를 선택합니다
  2. 이 연도 마이그레이션 버튼을 클릭합니다
전체 마이그레이션

전체 마이그레이션 버튼을 클릭하면 모든 연도의 데이터를 한 번에 Firebase로 옮깁니다.

주의 마이그레이션은 로컬 데이터를 Firebase로 복사하는 작업입니다. 기존 Firebase 데이터는 덮어쓰기됩니다.

캐시 관리

자동 캐시 정리

앱은 매주 금요일에 자동으로 캐시를 정리합니다.

  • Firebase IndexedDB 캐시를 삭제하여 성능을 유지합니다
  • 사용자 데이터는 삭제되지 않습니다 (localStorage와 Firebase는 유지)
수동 캐시 삭제

캐시 삭제 버튼을 클릭하면 즉시 캐시를 정리할 수 있습니다.

  • 앱이 느려지거나 이상 동작할 때 시도해보세요
  • 삭제 후 앱을 재시작하는 것을 권장합니다

암호화 설정

민감한 개인정보(성명, 전화번호, 주소)를 AES-256-GCM 방식으로 암호화할 수 있습니다.

암호화 활성화
  1. 설정 페이지에서 암호화 설정 섹션을 찾습니다
  2. 비밀번호 입력 버튼을 클릭합니다
  3. 비밀번호를 설정합니다 (최대 64자)
  4. 이후 저장되는 모든 시료의 민감 정보가 자동으로 암호화됩니다
비밀번호 변경

암호화 활성 상태에서 비밀번호를 변경할 수 있습니다.

  1. 비밀번호 변경 버튼을 클릭합니다
  2. 현재 비밀번호와 새 비밀번호를 입력합니다
  3. 모든 데이터가 새 비밀번호로 자동 재암호화됩니다
  4. 오류 발생 시 자동으로 롤백되므로 안전합니다
복구 키 시스템

비밀번호를 잊어버린 경우를 대비한 복구 키를 발급받을 수 있습니다.

  1. 암호화 활성화 시 복구 키(24자)가 자동으로 발급됩니다
  2. 복구 키는 반드시 안전한 곳에 기록해두세요 (화면에 한 번만 표시됨)
  3. 복구 키를 분실한 경우 설정에서 복구 키 발급/재발급 버튼으로 새로 발급받을 수 있습니다
  4. 재발급 시 기존 복구 키는 무효화됩니다
비밀번호 복구

비밀번호를 잊어버린 경우 복구 키로 비밀번호를 재설정할 수 있습니다.

  1. 암호화 비활성 상태에서 비밀번호 복구 버튼을 클릭합니다
  2. 발급받은 복구 키(24자)를 입력합니다
  3. 새 비밀번호를 설정합니다
  4. 모든 데이터가 새 비밀번호로 자동 재암호화됩니다
보안 주의사항
  • 비밀번호와 복구 키를 모두 잊어버리면 데이터를 복호화할 수 없습니다
  • 복구 시도는 5회로 제한되며, 초과 시 30분간 잠금됩니다
  • 복구 키는 클립보드에 복사 후 30초 뒤 자동으로 삭제됩니다

암호화 사양

  • 알고리즘: AES-256-GCM (Web Crypto API)
  • 키 유도: PBKDF2-HMAC-SHA256 (600,000 iterations)
  • 복합 키: 비밀번호 + 키 파일(sample-log.key) 결합
  • IV: 레코드별 랜덤 생성 (16바이트)
  • 암호화 필드: 성명, 전화번호, 주소, 지번 등
  • 복구 키: 24자 (~119비트 엔트로피)

암호화 마이그레이션

기존 평문 데이터를 일괄 암호화하거나, 암호화를 해제할 수 있습니다.

  1. 암호화 활성 상태에서 암호화 마이그레이션 섹션이 표시됩니다
  2. 전체 암호화 버튼으로 기존 데이터를 일괄 암호화합니다
  3. 마이그레이션 중 오류 발생 시 완료된 컬렉션까지만 유지되고, 나머지는 롤백됩니다
마이그레이션 전 백업 암호화 마이그레이션 전에 반드시 JSON 백업을 권장합니다. 대량 데이터의 경우 시간이 소요될 수 있습니다.

자주 묻는 질문 (FAQ)

데이터가 안 보여요. 어떻게 해야 하나요? ▼

먼저 화면 상단의 연도 선택을 확인하세요. 현재 연도와 다른 연도를 선택하면 해당 연도의 데이터만 보입니다.

그래도 안 보인다면:

  • 필터 설정을 "전체"로 변경해보세요
  • 고급 검색 조건을 모두 초기화해보세요
  • 브라우저 개발자 도구(F12)의 콘솔에서 오류를 확인해보세요
오프라인에서도 사용할 수 있나요? ▼

네, 가능합니다. 앱은 오프라인 우선 방식으로 설계되었습니다.

  • 모든 데이터는 브라우저의 localStorage에 저장됩니다
  • 인터넷이 없어도 데이터 입력, 조회, 수정, 삭제가 모두 가능합니다
  • Firebase는 선택 사항이며, 설정하지 않아도 앱이 정상 동작합니다
  • Firebase를 설정한 경우, 온라인 상태가 되면 자동으로 동기화됩니다
다른 PC에서도 같은 데이터를 보고 싶어요. ▼

Firebase를 설정하면 가능합니다.

  1. 첫 번째 PC에서 Firebase 설정 및 인증 파일 등록
  2. 전체 동기화 버튼을 클릭하여 데이터를 클라우드에 업로드
  3. 두 번째 PC에서 동일한 인증 파일을 등록
  4. 자동으로 데이터가 동기화됩니다

자세한 Firebase 설정 방법은 FIREBASE_SETUP_GUIDE.html를 참조하세요.

데이터 백업은 어떻게 하나요? ▼

여러 가지 방법이 있습니다:

  • JSON 저장: 가장 정확한 백업. JSON 저장 버튼을 클릭하여 파일로 저장
  • 엑셀 내보내기: 보고서 작성이나 외부 공유에 적합. 엑셀 내보내기 버튼 클릭
  • 자동 저장: Electron 앱에서 폴더를 지정하면 5초마다 자동 백업
  • Firebase 동기화: 클라우드에 실시간 백업 (설정 필요)

정기적으로 여러 방법을 병행하는 것을 권장합니다.

앱이 느려지거나 이상하게 동작해요. ▼

다음 순서로 시도해보세요:

  1. 설정 페이지에서 캐시 삭제 버튼 클릭
  2. 앱 재시작 (Electron) 또는 페이지 새로고침 (웹)
  3. 브라우저의 개발자 도구(F12)에서 콘솔 오류 확인
  4. 데이터가 너무 많은 경우 페이지당 항목 수를 줄여보세요 (50건 권장)
  5. 그래도 해결되지 않으면 관리자에게 문의하세요
엑셀 가져오기 시 오류가 나요. ▼

다음 사항을 확인하세요:

  • 엑셀 파일 형식이 .xlsx인지 확인 (구형 .xls는 지원 안 됨)
  • 필수 항목(성명, 전화번호 등)이 모두 입력되어 있는지 확인
  • 날짜 형식이 올바른지 확인 (예: 2026-02-15)
  • 특수문자나 수식이 포함되어 있지 않은지 확인
  • 엑셀 서식 다운로드로 받은 템플릿을 사용하는 것을 권장
암호화를 활성화한 후 비밀번호를 바꿀 수 있나요? ▼

네, 가능합니다. 설정 페이지에서 비밀번호 변경 버튼을 클릭하세요.

  1. 현재 비밀번호를 입력합니다
  2. 새 비밀번호를 입력합니다
  3. 모든 데이터가 새 비밀번호로 자동 재암호화됩니다

변경 중 오류가 발생하면 자동으로 롤백되므로 안전합니다.

암호화 비밀번호를 잊어버렸어요. ▼

복구 키가 있으면 비밀번호를 재설정할 수 있습니다.

  1. 설정 페이지의 암호화 섹션에서 비밀번호 복구 버튼을 클릭합니다
  2. 발급받은 24자 복구 키를 입력합니다
  3. 새 비밀번호를 설정하면 모든 데이터가 재암호화됩니다

주의: 복구 시도는 5회로 제한됩니다. 5회 초과 시 30분간 잠금됩니다. 비밀번호와 복구 키를 모두 분실하면 데이터를 복호화할 수 없습니다.

복구 키를 분실했어요. 재발급받을 수 있나요? ▼

네, 암호화가 활성화된 상태에서 재발급받을 수 있습니다.

  1. 설정 페이지에서 복구 키 발급/재발급 버튼을 클릭합니다
  2. 새로운 복구 키(24자)가 화면에 표시됩니다
  3. 반드시 안전한 곳에 기록해두세요 (클립보드 복사 후 30초 뒤 자동 삭제됨)

주의: 재발급하면 기존 복구 키는 즉시 무효화됩니다.

여러 시료 타입을 동시에 관리할 수 있나요? ▼

네, 각 시료 타입은 독립적으로 관리됩니다.

  • 토양, 수질, 퇴액비, 잔류농약, 중금속 시료는 별도로 저장됩니다
  • 메인 화면에서 시료 타입을 선택하여 전환할 수 있습니다
  • 각 타입마다 독립된 접수번호 체계가 사용됩니다
  • Firebase를 사용하는 경우 모든 타입이 동기화됩니다
